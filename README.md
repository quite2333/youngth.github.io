# 七夕 H5 · 引力是宇宙的慢动作

一个献给在美院学习的朋友的七夕页面：四步极简交互（滑动 + 一次长按），
全程由 Canvas 物理引擎驱动，无任何外部运行时依赖。

## 打开方式

- 直接双击 `index.html` 即可在浏览器中体验（**手机浏览器效果最佳**，移动优先设计：
  顶部 HUD 居中、刘海屏安全区适配、窄屏字号自动缩放、滑动灵敏度自适应、
  相撞时 Android 触觉震动反馈）。
- 发送给朋友：把 `qixi-h5` 文件夹整体上传到任意静态托管
  （GitHub Pages / Vercel / Netlify / 对象存储），拿到链接后微信/短信发送。

## 访问稳定性（国内网络）

- 页面**唯一的外部依赖是字体**，其余（物理引擎、音效、噪点、动效）全部内联，
  零外部 JS / 图片 / 音频文件。
- 字体走**国内镜像 fonts.loli.net**（Google Fonts 的境内镜像，可直连），
  且用 `media="print"` 非阻塞加载——镜像不可达时**不会阻塞页面渲染**，
  自动回退到系统字体（苹方/宋体/思源宋体等，观感依然统一）。
- 海外访问时，JS 会在 4 秒检测后自动兜底加载 Google Fonts 官方源。

## 体验流程

1. **入场** —— 绝对零度：噪点黑背景，极细公式淡入，两颗光点在轨道上孤独游荡。
2. **滑动** —— 引力扭曲：上滑（或滚轮/方向键 ↑）增强引力 `G`，
   轨道坍缩、拖尾拉长，背景坐标数据跳动。
3. **高潮** —— 长按干预：能量环呼吸，按住屏幕任意位置，
   两颗星冲向指尖，相撞瞬间爆出琥珀色流体波纹。
4. **落幕** —— 留白与诗意：色彩散去，文案逐字浮现，右下角 Mono 署名。

## 音效（Web Audio 实时合成，零外部文件）

- **太空底噪**（四层设计，星际穿越式黑暗氛围）：
  1. **地基**：重度低通的棕色噪声——生命维持系统的遥远嗡鸣，闷而重；
  2. **地鸣**：55/55.4Hz 失谐对 + 41Hz 低五度，0.8Hz 轻颤"呼噜"，
     像巨大的飞船引擎在深空缓缓运转（40-60Hz 的压力感）；
  3. **呼吸**：10 秒周期的 LFO 同步驱动音量与滤波截止，
     如宇宙潮汐缓慢起伏；附 0.05Hz 极慢音高漂移营造辽阔感；
  4. **虚空**：底噪送入 3 秒大厅混响，空间无限延伸；
     无旋律、无打击、无突变。滑动引力越强，底噪越收紧、音高越沉。
- **无缝循环**：噪声缓冲头尾交叉淡化 + 连续 LFO/正弦，循环无接缝咔哒声。
- **电影式淡入**：首次交互后 4 秒内把音量缓缓推高，像电影开场拉入宇宙。
- **音频闪避（Sidechain）**：相撞瞬间底噪瞬间压低 50%，2 秒后慢慢恢复，
  让玻璃撞击声显得无比清晰和震撼。
- **外放保护（防炸麦）**：主输出带硬限幅器（-12dB 阈值），任何叠加峰值都不会削波；
  小屏外放自动压低 41~55Hz 地鸣与次低频驱动（手机扬声器播不出且会拍边），
  480Hz 中频气息带相应提亮，保证外放可闻又不失真；耳机党不受影响。
- **相撞音效**（四层设计，非水滴声）：
  1. **玻璃质撞击**：FM 合成 2000Hz 载波 + 非谐金属泛音，像轻轻敲击玻璃颂钵，
     无频率骤降，高频清脆通透（外放也能听清）；
  2. **冰晶颗粒**：26 颗 3.4~8.6kHz 微晶体碎裂 + 14 粒冰尘，瞬间溶解；
  3. **Shimmer 尾音**：反馈环内颗粒移调器将尾音逐级**上移八度**，
     经 3 秒大厅混响扩散，形成天使般 4~5 秒的星尘余响；
  4. **低频重力波**：50Hz 次低音缓慢涌起、长释放——手机外放几乎听不到，
     是留给耳机党的深层惊喜。
- **立体声定位**：声像跟随手指 X 坐标（最左 -1 → 最右 +1），
  并叠加**哈斯效应**（对侧声道延迟 0~3ms），全息 3D 空间感。
- **注意事项**：浏览器自动播放策略要求，声音在**首次交互**（滑动/点击）后
  自动开启；右上角 `♪` 按钮可随时静音；页面隐藏时自动暂停省电。
  `?auto` 自动演示模式下无音效（没有用户手势）。

## 自定义

| 想改什么 | 在哪里改 |
| --- | --- |
| 署名（右下角） | `index.html` 顶部 `const SIGN = 'YOUR NAME'`（日期自动取当天） |
| 主题色（蓝/琥珀） | `index.html` 内 `:root` 中的 `--amber*` 变量 |
| 谢幕文案 | JS 中 `buildPoem()` 的 `LINES` 数组 |
| 引力强度 / 坍缩速度 | JS 中 `K`、`6.2e7` 等物理常数 |

## 预览模式

在 URL 末尾加 `?auto` 会自动走完整个流程（自动滑动 → 自动长按 → 相撞 → 谢幕），
方便快速预览全流程效果。
